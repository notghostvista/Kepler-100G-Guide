Kepler 100-G is a community based project of made up nations, each with their unique culture, currency, and more!\
\
This guide was created to guide you on how you can get started with the Kepler-100G Game from newbie to pro.

If you have any further questions, you may join the Kepler-100G Discord Server.\
\
